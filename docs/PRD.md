> Status: **draft** — to be written by the PRD skill.
> App ID: `app_zecy7nd27tk8`

## One-line idea

Photograph a coin or banknote and get its name, country, denomination, year, mint mark, composition, rarity, possible error/variety hints and an honest circulated/uncirculated value range with a confidence label, then track the collection's total worth. Built on a reusable Identify Engine (camera -> Gemini via Firebase AI Logic -> result card -> Room collection) shared later with StoneID and ThriftScan. First scan free with zero ads; shareable 'what's it worth' card.
