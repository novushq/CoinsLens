# C-4: Collection folders and items

- **Kind:** feature
- **Module:** `collection`
- **Owns paths:** `feature/collection/**`, `app/src/main/kotlin/app/novushq/coinlens/MainActivity.kt`, `app/src/main/kotlin/app/novushq/coinlens/di/AppModule.kt`

## Description

Screens for routes `Collection`, `Folder(folderId)`, `Item(itemId)`.
- Collection: summary header (total value, cost basis, gain/loss), folders grid with item count and value, "Unsorted" pseudo-folder for items with no folder, create/rename/delete folder (delete confirmation names consequence: "Delete 'Wheat cents'? Its 12 coins move to Unsorted.").
- Folder: items list (LazyColumn, stable keys) sorted by value desc / date / name; each row shows CoinFrame, name, year, grade, value.
- Item: edit grade (Grade enum picker), grade notes, purchase price, quantity, move folder, delete (confirm), open original scan (`Result(scanId)`), Share (`Share(scanId)`).
- Values via `ComputeCollectionValueUseCase` (grade-aware).

Only edit files under `feature/collection/**`. Replace the core-provided stubs in `CollectionEntry.kt` (`collectionGraph` and `collectionModule`); do not touch `:app`, `:core:*` or other features. Use designsystem tokens only, all four UI states via `UiStateSurface`, strings in `feature/collection/src/main/res/values/strings.xml`, ViewModel exposes immutable `StateFlow<UiState>` + `onAction`, unit tests for the ViewModel with fakes and `kotlinx-coroutines-test`. Compose previews for each state.

## Acceptance criteria

- [ ] Folders can be created, renamed and deleted; deleting a folder moves its items to Unsorted after a confirmation naming the consequence
- [ ] Folder screen lists items with name, year, grade and value and supports sorting by value, date and name
- [ ] Item edits to grade, notes, purchase price, quantity and folder persist in Room and update totals immediately
- [ ] Collection header shows total value, cost basis and gain/loss computed by ComputeCollectionValueUseCase
- [ ] ViewModel unit tests cover folder CRUD and item edit flows with fake repositories
