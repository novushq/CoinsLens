# C-8: Settings and legal

- **Kind:** feature
- **Module:** `settings`
- **Owns paths:** `feature/settings/**`, `app/src/main/kotlin/app/novushq/coinlens/MainActivity.kt`, `app/src/main/kotlin/app/novushq/coinlens/di/AppModule.kt`

## Description

Screen for route `Settings`: Plan status (Free with scans left / Pro), Go Pro → `Paywall(source="settings")`, **Restore purchases** (`EntitlementRepository.restore()`), Manage subscription (opens Play subscriptions deep link), value disclaimer text, privacy policy & terms links, "AI engine: Gemini (Firebase) / Demo data" row from `BuildConfig`-backed `AiInfo` provided by core, app version, reset onboarding (debug builds only), change persona.

Only edit files under `feature/settings/**`. Replace the core-provided stubs in `SettingsEntry.kt` (`settingsGraph` and `settingsModule`); do not touch `:app`, `:core:*` or other features. Use designsystem tokens only, all four UI states via `UiStateSurface`, strings in `feature/settings/src/main/res/values/strings.xml`, ViewModel exposes immutable `StateFlow<UiState>` + `onAction`, unit tests for the ViewModel with fakes and `kotlinx-coroutines-test`. Compose previews for each state.

## Acceptance criteria

- [ ] Restore purchases calls EntitlementRepository.restore and shows the outcome
- [ ] Plan status reflects Free (with remaining scans) or Pro from the allowance flow
- [ ] Manage subscription opens the Play Store subscriptions deep link
- [ ] The AI engine row shows whether Gemini or demo data is active
- [ ] Persona can be changed and persists; ViewModel unit tests cover restore success and failure
