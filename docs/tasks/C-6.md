# C-6: Onboarding persona quiz

- **Kind:** feature
- **Module:** `onboarding`
- **Owns paths:** `feature/onboarding/**`, `app/src/main/kotlin/app/novushq/coinlens/MainActivity.kt`, `app/src/main/kotlin/app/novushq/coinlens/di/AppModule.kt`

## Description

Screen for route `Onboarding` (3 pages, ≤60s):
1. Promise: "Know what your coins are worth" with the three wedge points (first scan free, no ads before your result, honest ranges).
2. Quiz "What brings you here?": Collector / Inherited coins / Metal detecting → `PreferencesRepository.setPersona`.
3. Camera priming (explain why, then request `CAMERA`), then `CompleteOnboardingUseCase` and navigate to `Capture` directly (first scan, no paywall, no ads).
- Skip is allowed on page 1 and 2 (persona defaults to COLLECTOR).

Only edit files under `feature/onboarding/**`. Replace the core-provided stubs in `OnboardingEntry.kt` (`onboardingGraph` and `onboardingModule`); do not touch `:app`, `:core:*` or other features. Use designsystem tokens only, all four UI states via `UiStateSurface`, strings in `feature/onboarding/src/main/res/values/strings.xml`, ViewModel exposes immutable `StateFlow<UiState>` + `onAction`, unit tests for the ViewModel with fakes and `kotlinx-coroutines-test`. Compose previews for each state.
