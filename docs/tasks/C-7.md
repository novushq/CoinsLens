# C-7: Paywall, subscriptions and rewarded scan

- **Kind:** feature
- **Module:** `paywall`
- **Owns paths:** `feature/paywall/**`, `app/src/main/kotlin/app/novushq/coinlens/MainActivity.kt`, `app/src/main/kotlin/app/novushq/coinlens/di/AppModule.kt`

## Description

This module **owns all billing and ads code** (policy `subscription_ads`). Screen for route `Paywall(source)`.
- RevenueCat `com.revenuecat.purchases:purchases:10.15.1`: `Purchases.configure(PurchasesConfiguration.Builder(app, key).build())` in this module's Koin/initializer, key from `BuildConfig`/manifest placeholder fed by gradle property `revenuecat.apiKey` (never committed). Offering packages: weekly, annual (3-day trial), lifetime; entitlement id `pro`. Prices and trial text come from the store package, never hardcoded.
- Provide `RevenueCatEntitlementRepository : EntitlementRepository` (isPro as Flow from `UpdatedCustomerInfoListener` + cached `getCustomerInfo`, works offline from cache) and register it in `paywallModule` so it overrides the core default.
- Custom Compose paywall (persona-tailored copy, see PRD table; record why custom in an ADR): headline per persona, 3 plan cards (annual preselected with "3-day free trial" badge), Continue, Restore purchases, terms/privacy links, close X.
- **Rewarded ad** (`play-services-ads:25.5.0`, test unit `ca-app-pub-3940256099942544/5224354917`, test app id `ca-app-pub-3940256099942544~3347511713` via manifest placeholder `admob.appId`): secondary button "Watch an ad for 1 free scan" → on `OnUserEarnedRewardListener` call `GrantBonusScanUseCase`; load lazily, main thread calls, `MobileAds.initialize` on IO the first time the paywall opens. Never initialised or shown for Pro users; no banners or interstitials.
- **Dummy mode**: when `revenuecat.apiKey` is absent, use `FakeBillingGateway` with the three plans at $4.99/$29.99/$59.99 labelled "(test)" and a purchase that flips isPro; when `admob.appId` is absent, `FakeRewardedAdGateway` grants the reward after a 1s simulated ad. Hide billing/ads behind `BillingGateway` and `RewardedAdGateway` interfaces inside this module.
- Cancelled purchase is silent; purchase success pops back to source. Record the monetization ADR (free vs gated, prices, entitlement id `pro`, why a custom paywall) in result.json `decisions`.

Only edit files under `feature/paywall/**`. Replace the core-provided stubs in `PaywallEntry.kt` (`paywallGraph` and `paywallModule`); do not touch `:app`, `:core:*` or other features. Use designsystem tokens only, all four UI states via `UiStateSurface`, strings in `feature/paywall/src/main/res/values/strings.xml`, ViewModel exposes immutable `StateFlow<UiState>` + `onAction`, unit tests for the ViewModel with fakes and `kotlinx-coroutines-test`. Compose previews for each state.

## Acceptance criteria

- [ ] Paywall shows weekly, annual (with 3-day trial) and lifetime plans with prices from the billing gateway, annual preselected
- [ ] Headline and benefit copy differ for COLLECTOR, INHERITED and DETECTORIST personas
- [ ] A completed purchase makes EntitlementRepository.isPro emit true and returns to the source screen; a cancelled purchase shows no error
- [ ] Watching the rewarded ad grants exactly one bonus scan via GrantBonusScanUseCase and is never offered to Pro users
- [ ] Restore purchases is available and reports success or 'nothing to restore'
- [ ] All billing and ads symbols live only in feature/paywall, with fake gateways used when API keys are absent, and ViewModel tests cover purchase, cancel, restore and reward
