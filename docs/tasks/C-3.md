# C-3: Home dashboard with total worth

- **Kind:** feature
- **Module:** `home`
- **Owns paths:** `feature/home/**`, `app/src/main/kotlin/app/novushq/coinlens/MainActivity.kt`, `app/src/main/kotlin/app/novushq/coinlens/di/AppModule.kt`

## Description

Screen for route `Home`.
- Hero: total collection worth (`CollectionSummary.totalMid`, displaySmall serif, tabular figures) with low–high range underneath and item count; count-up animation once.
- Scan CTA (large extended FAB, the only accent): routes to Capture if `canScan`, else to `Paywall(source="quota")`. Show allowance line for free users ("1 free scan left" / "Free scan used — go Pro or watch an ad for one more"), hidden for Pro.
- Recent scans (last 10) as horizontal row of `CoinFrame` thumbnails with name and value → `Result(scanId)`.
- Entry to Collection and Settings (top bar icon with contentDescription).
- Empty state for new users: illustration-free, copy "Scan your first coin — it's free".

Only edit files under `feature/home/**`. Replace the core-provided stubs in `HomeEntry.kt` (`homeGraph` and `homeModule`); do not touch `:app`, `:core:*` or other features. Use designsystem tokens only, all four UI states via `UiStateSurface`, strings in `feature/home/src/main/res/values/strings.xml`, ViewModel exposes immutable `StateFlow<UiState>` + `onAction`, unit tests for the ViewModel with fakes and `kotlinx-coroutines-test`. Compose previews for each state.

## Acceptance criteria

- [ ] Home shows total worth, low–high range and item count from CollectionSummary using tabular figures
- [ ] Scan CTA routes to Capture when allowance permits and to Paywall(source=quota) otherwise
- [ ] Allowance copy reflects free remaining, bonus scans and is hidden for Pro users
- [ ] Recent scans list opens Result for the tapped scan
- [ ] Empty, loading, error and success states render and are unit-tested in the ViewModel
