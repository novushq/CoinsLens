# C-5: Shareable what's-it-worth card

- **Kind:** feature
- **Module:** `share`
- **Owns paths:** `feature/share/**`, `app/src/main/kotlin/app/novushq/coinlens/MainActivity.kt`, `app/src/main/kotlin/app/novushq/coinlens/di/AppModule.kt`

## Description

Screen for route `Share(scanId)`.
- Renders a 1080×1350 (4:5, reels/Instagram friendly) card: brass ring coin photo, serif coin name, year · country, value range ("$0.10 – $25"), confidence label, small "Identified with CoinLens" mark. Light and dark card variants toggle.
- Render with `GraphicsLayer.toImageBitmap()` (Compose `rememberGraphicsLayer`) or an offscreen `Canvas`; save PNG to `cacheDir/share/`, share via `FileProvider` + `Intent.ACTION_SEND` (declare the provider in this module's manifest with authority `${applicationId}.share`).
- Buttons: Share, Save to Photos (MediaStore, no storage permission on API 29+).

Only edit files under `feature/share/**`. Replace the core-provided stubs in `ShareEntry.kt` (`shareGraph` and `shareModule`); do not touch `:app`, `:core:*` or other features. Use designsystem tokens only, all four UI states via `UiStateSurface`, strings in `feature/share/src/main/res/values/strings.xml`, ViewModel exposes immutable `StateFlow<UiState>` + `onAction`, unit tests for the ViewModel with fakes and `kotlinx-coroutines-test`. Compose previews for each state.

## Acceptance criteria

- [ ] The card renders the coin photo, name, year, country, value range and confidence label from the ScanRecord
- [ ] Share produces a PNG via FileProvider and opens the system share sheet
- [ ] Save to Photos writes the PNG through MediaStore without requesting storage permission on API 29+
- [ ] Light and dark card variants can be toggled and both render correctly
- [ ] Card layout logic (text formatting of value range) is unit-tested
